# Original source archive

`codespace-project-reviver.zip` is the original uploaded source snapshot, retained unchanged for provenance/recovery. The project was extracted into the repository root; generated Gradle/CMake caches were intentionally not extracted. The original archive's Gradle wrapper JAR was corrupt, so the working copy at `../gradle/wrapper/gradle-wrapper.jar` was restored from the matching Gradle 9.3.1 upstream Git blob and checksum-verified. Gradle does not read or build from this archive.
